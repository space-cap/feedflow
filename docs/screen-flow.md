# FeedFlow 화면 흐름 문서

## 1. 문서 목적

이 문서는 MVP에서 구현할 화면과 사용자 흐름을 정의한다. 프론트엔드 라우팅, 주요 상태, 화면 간 이동 기준으로 사용한다.

## 2. 라우트 구조

| 화면 | 경로 | 인증 | 설명 |
| --- | --- | --- | --- |
| 로그인 | `/login` | 비회원 | 이메일 로그인 |
| 회원가입 | `/signup` | 비회원 | 계정 생성 |
| 비밀번호 재설정 | `/password/reset` | 비회원 | 예정 |
| 홈 피드 | `/` | 회원 | 팔로우 기반 피드 |
| 추천 피드 | `/explore` | 선택 | 공개 게시글 피드 |
| 게시글 상세 | `/posts/:id` | 선택 | 게시글과 댓글 |
| 프로필 | `/users/:handle` | 선택 | 사용자 프로필과 게시글 |
| 프로필 편집 | `/settings/profile` | 회원 | 내 프로필 수정 |
| 알림 | `/notifications` | 회원 | 알림 목록 |
| 설정 | `/settings` | 회원 | 계정 설정 |
| 차단 목록 | `/settings/blocks` | 회원 | 차단 사용자 관리 |
| 팔로우 요청 | `/settings/follow-requests` | 회원 | 받은 팔로우 요청 승인/거절 |
| 관리자 신고 | `/admin/reports` | 관리자 | 신고 목록 |
| 관리자 신고 상세 | `/admin/reports/:id` | 관리자 | 신고 처리 |

## 3. 공통 레이아웃

### 3.1 데스크톱

- 좌측: 주요 내비게이션
- 중앙: 피드 또는 상세 콘텐츠
- 우측: 추천 사용자, 서비스 공지, 간단 검색 영역

### 3.2 모바일

- 상단: 현재 화면 제목과 주요 액션
- 본문: 단일 컬럼
- 하단: 홈, 탐색, 알림, 설정 또는 로그인 탭

## 4. 핵심 화면

### 4.1 로그인

입력:

- 이메일
- 비밀번호

액션:

- 로그인
- 회원가입 화면 이동
- 비밀번호 재설정 화면 이동

상태:

- 입력 오류
- 로그인 실패
- 로딩
- 성공 후 홈 이동

### 4.2 회원가입

입력:

- 이메일
- 비밀번호
- 핸들
- 표시 이름

액션:

- 회원가입
- 로그인 화면 이동

검증:

- 이메일 형식
- 비밀번호 최소 길이
- 핸들 중복
- 표시 이름 필수

성공 흐름:

```text
회원가입 성공 -> 자동 로그인 또는 로그인 화면 -> 홈 피드
```

### 4.3 홈 피드

구성:

- 게시글 작성 진입 버튼
- 팔로우한 사용자 게시글 목록
- 빈 상태 메시지
- 무한 스크롤

게시글 카드 액션:

- 상세 보기
- 좋아요
- 댓글
- 재게시
- 더보기 메뉴

빈 상태:

- 팔로우한 사용자가 없으면 추천 피드로 이동할 수 있는 액션을 제공한다.

### 4.4 추천 피드

구성:

- 공개 게시글 목록
- 최신순 또는 단순 인기순
- 무한 스크롤

목적:

- 신규 사용자가 팔로우할 계정을 찾을 수 있게 한다.
- 홈 피드가 비어 있을 때 대체 탐색 경로가 된다.

### 4.5 게시글 작성

표시 방식:

- 데스크톱: 모달 또는 상단 작성 영역
- 모바일: 전체 화면 작성 화면

입력:

- 본문
- 공개 범위

제약:

- 1자 이상 500자 이하
- 공백만 있는 게시글 작성 불가

성공 흐름:

```text
작성 성공 -> 작성창 닫기 -> 홈 또는 프로필 피드 상단에 반영
```

### 4.6 게시글 상세

구성:

- 원본 게시글
- 댓글 작성 영역
- 댓글 목록
- 좋아요, 댓글, 재게시 액션

상태:

- 삭제된 게시글
- 숨김 처리된 게시글
- 접근 권한 없음
- 로딩

### 4.7 프로필

구성:

- 프로필 이미지
- 표시 이름
- 핸들
- 소개글
- 팔로워 수
- 팔로잉 수
- 팔로우 또는 언팔로우 버튼
- 게시글 목록

상태:

- 내 프로필이면 프로필 편집 버튼 표시
- 비공개 계정이면 승인된 팔로워에게만 게시글 표시
- 차단한 사용자 또는 나를 차단한 사용자면 제한 화면 표시

### 4.8 프로필 편집

입력:

- 표시 이름
- 소개글
- 프로필 이미지 URL
- 비공개 계정 여부

액션:

- 저장
- 취소

성공 흐름:

```text
저장 성공 -> 프로필 화면으로 이동 또는 현재 화면에 성공 상태 표시
```

### 4.9 알림

구성:

- 알림 목록
- 읽음/안 읽음 상태
- 전체 읽음 버튼
- 개별 읽음 버튼

알림 종류:

- 좋아요
- 댓글
- 팔로우
- 재게시

액션:

- 알림 클릭 시 관련 게시글 또는 프로필로 이동한다.

### 4.10 설정

구성:

- 프로필 편집
- 팔로우 요청 관리
- 차단 목록
- 로그아웃
- 계정 공개 여부

MVP에서는 계정 삭제와 이메일 변경은 제외할 수 있다.

### 4.11 차단 목록

구성:

- 내가 차단한 사용자 목록
- 차단 해제 버튼

상태:

- 차단 사용자가 없을 때 빈 상태를 표시한다.

## 5. 관리자 화면

### 5.1 신고 목록

구성:

- 신고 상태 필터
- 신고 대상 유형 필터
- 신고 목록
- 신고 시각
- 신고 사유

액션:

- 신고 상세 이동
- 상태 변경

### 5.2 신고 상세

구성:

- 신고자 정보
- 대상 게시글 또는 사용자 정보
- 신고 사유
- 기존 처리 이력

액션:

- 게시글 숨김
- 계정 정지
- 신고 해결
- 신고 기각

## 6. 주요 사용자 흐름

### 6.1 신규 사용자 첫 사용

```text
회원가입
-> 홈 피드
-> 빈 상태 확인
-> 추천 피드 이동
-> 사용자 팔로우
-> 홈 피드 복귀
-> 게시글 작성
```

### 6.2 게시글 상호작용

```text
홈 피드
-> 게시글 좋아요
-> 게시글 상세
-> 댓글 작성
-> 작성자 프로필 이동
-> 팔로우
```

### 6.3 비공개 계정 팔로우

```text
프로필 방문
-> 팔로우 요청
-> 요청 상태 pending 표시
-> 상대가 승인
-> 알림 수신
-> 게시글 조회 가능
```

### 6.4 신고 처리

```text
회원이 게시글 신고
-> reports 생성
-> 운영자 신고 목록 확인
-> 신고 상세 확인
-> 게시글 숨김 또는 신고 기각
-> moderation_actions 기록
```

## 7. 화면 상태 기준

모든 주요 화면은 다음 상태를 처리한다.

- 초기 로딩
- 데이터 없음
- 인증 필요
- 접근 권한 없음
- 네트워크 또는 서버 오류
- 저장 중
- 저장 성공
- 검증 오류

## 8. MVP UI 우선순위

1. 로그인과 회원가입
2. 홈 피드
3. 게시글 작성
4. 게시글 상세과 댓글
5. 프로필
6. 팔로우
7. 알림
8. 설정과 차단 목록
9. 관리자 신고 화면
